### 1. Fixed: Missing lines in data table ✅

**Problem:**

- Email sometimes missing one or more product lines
- Old code: `.values[0]` → **crash** (IndexError)
- System stopped working when data missing

**Solution:**

- New function `get_value_safe(df, line_name)`
- Returns value if exists, `None` if missing
- Message: "WARNING: Missing line X!"
- Database saves only products that exist

**Code:**

```python
def get_value_safe(df, line_name):
    result = df.loc[df['Line'] == line_name, 'Execution']
    if len(result) > 0:
        return result.values[0]
    else:
        print(f"WARNING: Missing line {line_name}!")
        return None
```

**In `save_to_database()`:**


### 2. Fixed: INSERT vs UPDATE logic (UPSERT) ✅

**Problem:**

- March had 2 rows (Segment B: Product 1, Product 2)
- Script checked: "does month 202603 exist?" → YES
- Did UPDATE for all products
- UPDATE for Segment A didn't work (Segment A had no rows for March yet)
- Segment A **wasn't saved to database!**

**Old logic (WRONG):**

```python
if month_exists:
    UPDATE everything  # ← But Segment A has no rows, so UPDATE doesn't work!
else:
    INSERT everything
```

**New logic (CORRECT) - UPSERT:**

```python
for each_row in data:
    if product_exists_for_this_month:
        UPDATE
    else:
        INSERT
```

**Implementation:**

```python
inserted = 0
updated = 0

for row in data:
    report_date, segment, product, value, month = row
    
    # Check if THIS SPECIFIC product exists
    query_check = f"""
        SELECT COUNT(*) FROM schema.table 
        WHERE SEGMENT = '{segment}' 
        AND PRODUCT = '{product}' 
        AND MONTH = '{month}'
    """
    cursor.execute(query_check)
    exists = cursor.fetchone()[0]
    
    if exists == 0:
        # INSERT - product doesn't exist
        insert_sql = "INSERT INTO schema.table VALUES (?,?,?,?,?)"
        cursor.execute(insert_sql, row)
        inserted += 1
    else:
        # UPDATE - product exists
        update_sql = """
            UPDATE schema.table 
            SET VALUE = ?, REPORT_DATE = ?
            WHERE SEGMENT = ? AND PRODUCT = ? AND MONTH = ?
        """
        cursor.execute(update_sql, (value, report_date, segment, product, month))
        updated += 1

print(f"\nInserted: {inserted}, Updated: {updated}")
```

**Test result:**

```
Inserted: 4, Updated: 2
```

✅ Segment A correctly saved! (4 new rows + 2 updated Segment B)

## 💡 KEY INSIGHT

**Problem was subtle:**

- Checking "does month exist" instead of "does product exist"
- This is typical case where **granularity of checking** is crucial
- Solution: check at lowest level (product + month)

**Lesson learned:**
> Business conditions should be checked at the level that actually changes, not at aggregate level!
