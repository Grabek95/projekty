## 🎓 KEY LESSONS

1. **Relative imports in Python** - requires `__init__.py` and proper configuration
2. **Global variables in modules** - must be set through `module.variable`
3. **CORS** - without it, frontend can't connect to backend
4. **React lifecycle** - `useEffect(() => {}, [])` runs on component mount
5. **Async in React** - always use `async/await` for API calls
6. **Error handling** - always try/catch in async functions
7. **2 servers** - development requires backend + frontend simultaneously
