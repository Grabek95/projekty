### 6. Intelligent Column Detection Logic ✅

**Problem:**

- Email has varying number of columns (2-12 throughout year)
- Old logic: `if len(date_columns) == 2` → doesn't work in May, June...
- Need to check **date** of last column, not **count** of columns

**Solution:**

```python
def fetch_data():
    # Get date columns
    date_columns = [col for col in df.columns 
        if col[0] not in ['PERIOD', 'TOTAL'] and '-' in str(col[0])]
    
    # Check date of last column
    last_column = date_columns[-1]
    last_date = last_column[0]  # e.g. "2026-02-01"
    current_month = datetime.now().strftime("%Y-%m")  # e.g. "2026-03"
    
    if last_date.startswith(current_month):
        # Last column = current month (already appeared)
        current_month_column = date_columns[-1]
        previous_month_column = date_columns[-2]
        # Fetch current + previous
    else:
        # Last column = previous month (current not yet)
        current_month_column = None
        previous_month_column = date_columns[-1]
        # Fetch only previous
```

**Now works regardless of column count!** ✅
